# IDG Collaboration Map

An aggregate view of the International Development Group (IDG): who the members are by institution type and expertise, and where collaboration is possible.

- Live page: enable GitHub Pages for this repository (Settings > Pages > Deploy from branch > `main` / root).
- Totals only. The page contains no names, contact details or individual records.
- Any group with fewer than 3 members is shown as "<3".
- Counts come from keyword matching on self-reported form answers, so they are indicative.
- The Infographic tab can export four share-ready PNG slides.

Never commit the roster Excel file or the chat export to this repository. The `.gitignore` blocks common data file types as a safety net.
